# Cox Ring of Toric

THEOREM 2.5.4 Let X be a normal Q-factorial projective variety of dimension n. Then X is toric if and only if the Cox ring is a polynomial ring generated by n C .X / variables, in which case the invariant divisors correspond to the coordinate hyperplanes.
