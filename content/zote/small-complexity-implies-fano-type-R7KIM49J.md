# small complexity implies fano type

LEMMA 5.3 Assume Theorem 1.2n 1. Let X be a Q-factorial projective variety of dimension n. Suppose that .X; / is a divisorially log terminal pair and .KX C / is nef. If the complexity of .X; / is less than 1, then X is of Fano type. In particular, X is a toric variety. <a href="zotero://open/library/items/Y3HVA67C?page=35&#x26;annotation=F3BM6RKI">(page)</a></a> (<a href="zotero://select/library/items/V29V2BPE">Brown et al., 2018, p. 957</a>)
